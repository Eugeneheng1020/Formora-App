# Formora 是什么

Formora 是给独立开发者用的多 Agent 工作台：每个 Agent 对应一个真实岗位——产品设计、研发、测试、数据分析、运营——一个需求在这些岗位之间流转。你是老板，Agent 是替你干活的同事。

## 五个区域

左侧竖栏从上到下：

- **消息**：和 Agent 的对话。单聊找一个 Agent；群聊里 @ 谁就交给谁，不 @ 就按任务性质自动分配。Agent 能读写项目文件、跑命令、上网查资料，每一步都在对话里显示成一张卡片，要你批准的步骤停在卡片上等你点「允许」。列表按「全部 / 进行中 / 已完成」筛选，右上角的加号发起新对话或建群。
- **Agent**：创建和管理 Agent：头像、名字、岗位、主模型和备用模型、能进哪些项目、权限模式、启用哪些 Skill 和 MCP。
- **看板**：对话的另一种看法。一个对话是一张画布，每次派活是一张卡片，谁交给了谁用线连着；点开卡片看它的「运行过程」，也能直接在画布上补充要求，或 @ 人把活接着派下去。
- **文件**：当前项目文件夹的文件树和预览。Agent 写的文件都在这里，对话里的「在文件中查看」会直接跳到那个文件。
- **设置**：账户、模型服务商、Skills、MCP、Hooks、通知、电脑操作、归档，以及 Bob。

## 项目

Formora 里的一切都属于一个项目：项目就是你电脑上的一个文件夹。左下角是当前项目的名字，点它可以切换项目、新建项目（在选的位置里建一个新的空文件夹）、打开已有项目（直接用电脑上已有的文件夹）或管理项目。对话、Agent 写的文件都跟着项目走；一个 Agent 要在「模型与权限」里被授权了某个项目，才能在那里干活。

## Bob

Bob 在设置里：设置的每一页右下角都有他的圆形按钮，点开是和他对话的浮窗；「设置 → Bob」这一页选他用的模型和权限模式、决定他能不能操作电脑，下面是一叠「能问他什么」的卡牌：一次看一张，问题和他的回答示例都在牌上，左右翻，「问 Bob」直接问他；他的浮窗空着时，也按类列出这些问题，点一下就问。他回答关于 Formora 的问题、查现在的情况（有哪些 Agent、任务做到哪、文件在哪），也能替你接入 MCP 服务、创建 Skill、在项目里建文件夹、改通知设置、在浏览器里打开网址。他还能直接动手：用所有已安装的 Skill 和所有已启用 MCP 服务的全部工具（不用给他启用），在当前项目里写文件、改文件、运行命令（和 Agent 一样只在项目文件夹里）。他有一份自己的记忆，不分项目：你说以后都要怎样，他会记下来，每次对话都带着；想看他记了什么、或者让他全忘掉，直接跟他说。他动手前问不问你，看「设置 → Bob」的「权限模式」，三档和 Agent 一样，默认「每次询问」：看文件、搜索、读 Skill、记东西、只读的 MCP 工具直接做，其余每一步先弹一张卡片等你点「允许」；选「允许写入」，写文件、改设置也直接做，读网页、运行命令仍先问；选「全部放行」，都直接做。不管哪一档，危险命令（删除、sudo 这类）、接入 MCP 服务、清空记忆、会删数据的 MCP 工具都先问你。他写过的文件，那一步下面有「撤销」。在「设置 → Bob」打开「允许操作电脑」后，他还能操作这台 Mac：看屏幕、点按和打字、用脚本控制其他应用；看屏幕不问，每次回答第一次动手时问你一次（「全部放行」时不问），屏幕顶部的停止条随时能停（只有官网下载的版本有）。给他文件：点输入框左边的回形针、把文件拖进浮窗，或者直接粘贴图片；文件放在 Formora 自己的文件夹里，不进项目。文字文件他直接读，图片给看得懂图的模型看，视频截几张画面连同时长给他看（听不到声音）。输入框里打 / 能看到他的指令：/clear、/memory、/help、/dump、/export、跳到各个设置页，以及 /skill:名字 按某个 Skill 的做法来做。
