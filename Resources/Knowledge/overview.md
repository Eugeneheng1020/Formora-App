# Formora 是什么

Formora 是给独立开发者用的多 Agent 工作台：每个 Agent 对应一个真实岗位——产品设计、研发、测试、数据分析、运营——一个需求在这些岗位之间流转。你是老板，Agent 是替你干活的同事。

## 五个区域

左侧竖栏从上到下：

- **消息**：和 Agent 的对话。单聊找一个 Agent；群聊里 @ 谁就交给谁，不 @ 就按任务性质自动分配。Agent 能读写项目文件、跑命令、上网查资料，每一步都在对话里显示成一张卡片，要你批准的步骤停在卡片上等你点「允许」。列表按「全部 / 进行中 / 已完成」筛选，右上角的加号发起新对话或建群。
- **Agent**：创建和管理 Agent：头像、名字、岗位、主模型和备用模型、能进哪些项目、权限模式、启用哪些 Skill 和 MCP。
- **看板**：对话的另一种看法。一个对话是一张画布，每次派活是一张卡片，谁交给了谁用线连着；点开卡片看它的「运行过程」，也能直接在画布上补充要求，或 @ 人把活接着派下去。
- **文件**：当前项目文件夹的文件树和预览。Agent 写的文件都在这里，对话里的「在文件中查看」会直接跳到那个文件。
- **设置**：账户、模型服务商、Skills、MCP、Hooks、通知、电脑操作、归档，以及 Bob。

## 项目

Formora 里的一切都属于一个项目：项目就是你电脑上的一个文件夹。左下角是当前项目的名字，点它可以切换、新建或管理项目。对话、Agent 写的文件都跟着项目走；一个 Agent 要在「模型与权限」里被授权了某个项目，才能在那里干活。

## Bob

Bob 在设置里：设置的每一页右下角都有他的圆形按钮，点开是和他对话的浮窗；「设置 → Bob」这一页选他用的模型、列着能问他的事。他回答关于 Formora 的问题、查现在的情况（有哪些 Agent、任务做到哪、文件在哪），也能替你接入 MCP 服务、创建 Skill、在项目里建文件夹、改通知设置、在浏览器里打开网址。看项目文件和搜索他直接做；读网页和要改东西都会先弹一张卡片等你点「允许」。
