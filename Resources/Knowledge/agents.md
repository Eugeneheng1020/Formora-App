# Agent 与协作

## 五个岗位

- **产品设计**：把一句话想法澄清成需求，写 PRD，负责交互和视觉说明。
- **研发**：技术方案和代码，能在项目文件夹里跑命令。
- **测试**：按验收标准写用例、跑验证、报缺陷。
- **数据分析**：定指标口径、分析数据、设计埋点。
- **运营**：运营计划、面向用户的文案、效果复盘。

同一个岗位可以建多个 Agent，名字显示成「岗位（名字）」，比如「研发（前端）」。在「Agent」区右上角的加号创建。

## Agent 能做什么

- 读、找、搜项目里的文件，新建和修改文件；研发还能跑命令。
- 搜索网络、读网页正文、在你的浏览器里打开网址。
- 用它启用的 Skill 和 MCP 工具；在对话里接入新的 MCP 服务（一定先问你）。
- 计划模式（`/plan`）里用计划清单列步骤（显示在输入框上方；没开计划模式它不列计划，你可以用 `/todo 文字` 自己加）、用选项卡片问你问题（推荐项标出，几个问题能回上一步改答案；它直接在回复里列几个方案让你挑时，Formora 也会做成同样的卡片）、记下以后要记得的事。计划还有没做完的步骤它就停下来时，Formora 会自动催它接着做，一次任务最多催 3 次——只在这一轮就是在做这份计划时才催（你点了「按这个计划做」、说了「继续」，或者它这一轮自己动过计划）；你换了话题，它答完就结束，计划原地等着，说「继续」再接上。它没在工作时，计划条右端的 × 能关掉计划：没做完的步骤作废，它之后不再按这份计划做。
- 它工作时你照样能发消息：它做完手上这一步就先处理你这条，再决定原来的事要不要接着做。正在跑的命令超过 3 秒还没完，会转到后台继续跑，不让你干等；委派出去的子任务要等它交回。等不及就点「停止」：手上的活停下，你排队的那条消息它接着就回，不用再发一遍。

## 权限模式

在 Agent 的「模型与权限」里设：

- **每次询问**：看项目文件和搜索以外的每一步都先问你。
- **允许写入**（默认）：看和写项目文件、搜索直接做；读网页、跑命令先问你。
- **全部放行**：都直接做。

删除、sudo、改写 git 历史、下载后直接运行这类危险命令，「每次询问」「允许写入」下都先问你；「全部放行」下直接执行，选它就是完全信任这个 Agent。「旁审」开关默认关，想要另一个模型在旁边把关时打开：另一个模型（「设置 → Bob」选的模型，没选就用这个 Agent 自己的）在旁边看它干活，改完文件、跑完命令的每一步和最后的回答都看一眼，没问题不出声，有问题就提醒它，分「提醒 / 担心 / 必须停」三级；每看一次多一次模型调用——一次只看一眼，上一眼没看完时做完的步骤攒到下一眼一起看，所以一轮通常只有两三次。「提醒」等它这一轮做完才显示；这期间它要是又改过提醒说的那个文件，这条提醒就作废（说的是旧版本）。「允许操作电脑」开关默认关：打开后这个 Agent 能看屏幕、点按和打字、用脚本控制其他应用（要先在「设置 → 电脑操作」给系统权限；只有官网版有）。它第一次动手前会弹卡片列出要做的步骤，你允许后这次任务里不再问；每做一步它会自己等画面稳定、看窗口里变了什么、对照自己写的预期判断有没有做到，不对就换做法，同一步最多再试 2 次，还不行就停下来问你；整件事做完，旁审会拿着最后一张截图对照你的要求验收；动手时屏幕顶部有停止条，按 ⌘ + Esc、点「停止」或在别的应用里动一下鼠标键盘就会停。Agent 不能操作 Formora 自己的窗口。打开后它还能跑 AppleScript 脚本（访达、Safari、备忘录这类支持脚本的应用，用脚本比点按更稳），能查看和运行你在「快捷指令」里做好的快捷指令；脚本第一次控制某个应用时，macOS 会问你一次。

## 群聊

- @ 谁就交给谁；@ 几个就依次回答。
- 不 @ 任何人：调度员按任务性质选一个成员——同岗位选空闲的，接着谁的活就给谁；对话里会写一行「分配给 X：理由」。
- 接力：一个成员做完自己的部分，可以交给下一个岗位（比如产品设计交给研发），对话里一行「A → B」写着交待。一条消息最多交接 6 次、50 万 token，接力中输入框上方有带「停止」的横幅。
- 群设置里可以在这个群停用某个成员。

## 委派

Agent 可以把一件界定清楚的事委派给同事或自己的「分身」（同岗位同模型，但不带这段对话），几件一起做。每件事是一个子任务，从卡片上的「打开子任务」能看过程，报告会交回给它。帮手要你批准的操作，会同时出现在原对话的卡片上。一次最多委派 8 件，同时 4 件。

## 自主运行

`/loop N` 连续跑 N 轮；`/goal 目标` 一轮一轮做，Agent 说做到了由另一个 Agent 只读复核，没通过就带着意见接着做。都最多 10 轮，随时能停。

## 记忆

记忆分三层，外加 Bob 自己的一层：

- **全局**：关于你的、任何项目都适用的事——你的背景、沟通方式、红线（比如「删除前先问」）。每个 Agent 和 Bob 都读得到。
- **项目**：这个项目的决定（带理由，包括你否决的方案）、约定、踩过的坑。这个项目里的所有 Agent 共用。
- **Agent**：你对某个岗位产出的要求（比如对产品设计：「PRD 每条需求带验收标准」）。只有它自己读得到，不分项目。
- **Bob**：你对 Bob 的要求、他操作 Formora 的经验。不分项目；他也读全局那层。

**只带目录，正文按需读。** 每次对话只把「目录」交给 Agent——每条记忆一行。大多数记忆就是那一行；少数带正文的（比如一个决定的理由），Agent 觉得和手上的事有关时才去读。各层有条数上限（全局 20、每个项目 30、每个 Agent 10、Bob 20），满了它得先合并或忘掉旧的。半年多没用到的条目不再列给它，`/memory` 里另外灰色列出，它再用到就恢复。

**什么才会被记下。** 只有四种时候：你明确说「记住」；你纠正了它；你在几个方案里拍了板；一件事先失败、后来它找到了正确做法。前三种必须能逐字对上你说过的话（你在选项卡片上选的也算；你只回一个「B」「好」来拍板，它就引用那整条回复）——对不上，程序直接退回，不记；它自己的提议、猜测、任务进度、文件里已有的内容都不记。

**什么时候记。** 干活时当场记；另外，一条对话闲置半小时后，Formora 会在后台回头看一遍有没有漏记的（每条对话每天最多一次，多数时候什么都不记）。以前「每次用过工具就自动整理一遍」的做法已经取消。

**你怎么看、怎么管。** 每次记下、更新或忘掉，对话里都会出现一行小字，比如「记下了（全局）：删除前先说清影响、问过再删」，旁边有「撤销」，记错了点一下就回去。`/memory` 列出这条对话用得到的三层，只读。事后想清理，在对话里说「忘掉 XX」。删掉 Agent 时，它自己那层一起删；它写进项目层的留着，别的 Agent 还在用。记忆文件在 `~/.formora/memory`（每条一个 Markdown 文件）；升级前的旧记忆原样收在里面的 `_legacy` 文件夹，不再使用。

## 上下文

对话太长时会自动压缩成摘要，原文折叠保留；输入框右下角的圆环是上下文占用，快满时会提示用 `/compact`。

输入框左下角的「推理强度」属于这一条对话，菜单只列这个 Agent 主模型真有的档（比如 DeepSeek V4 只有 低 / 高 / 最高，Gemini 3.1 Pro 只有 低 / 高 且关不掉，只有开关的模型显示 自动 / 关闭 / 开启）；换了模型后原来选的档没有了就自动就近降一档。服务商拒绝了某一档，以后菜单就不再列它，当次同一个模型换下一档重发。

## 子代理

子代理是按目的定义的专用助手，不是 Agent 列表里的岗位：有英文名字（也是指令，比如 `/scout`）、一句中文简介、自己的系统提示词、工具档位（只读 / 可写 / 可执行命令）。没有头像和自己的对话，被派活时在干净的上下文里跑一个子任务，做完交回报告。在对话里（或看板的输入框里）`/agent 写清目的` 创建：你只写核心目的，回车就自动开始，模型按一份内部的「撰写指南」把名字、简介、工具档位和系统提示词都写好、直接存下，全程没有弹窗；做完对话里出现一行「已创建子代理 名字」，看板上在那张卡片的「运行过程」里。`/名字 任务` 直接派；Agent 也会按描述自己派。名字用英文（小写字母、数字和 -），打指令时不用切输入法；你以前起的中文名照常能用。「设置 → SubAgent」只看和删除，不能在那里新建或修改：要改就改它的文件（标题栏「在 Finder 中打开」），或者删了用 `/agent 目的` 重建。要集中查看、改或删，去「设置 → 子代理」。定义是 Markdown 文件，在项目的 `.formora/agents/` 或全局的 `~/.formora/agents/`，和 Claude Code 的 `.claude/agents/` 一个格式，项目里已有的也直接能用。内置三个：探路、评审、查资料。
