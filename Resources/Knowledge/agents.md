# Agent 与协作

## 五个岗位

- **产品设计**：把一句话想法澄清成需求，写 PRD，负责交互和视觉说明。
- **研发**：技术方案和代码，能在项目文件夹里跑命令。
- **测试**：按验收标准写用例、跑验证、报缺陷。
- **数据分析**：定指标口径、分析数据、设计埋点。
- **运营**：运营计划、面向用户的文案、效果复盘。

同一个岗位可以建多个 Agent，名字显示成「岗位（名字）」，比如「研发（前端）」。在「Agent」区右上角的加号创建。

## Agent 能做什么

- 读、找、搜项目里的文件，新建和修改文件；研发还能跑命令。
- 搜索网络、读网页正文、在你的浏览器里打开网址。
- 用它启用的 Skill 和 MCP 工具；在对话里接入新的 MCP 服务（一定先问你）。
- 计划模式（`/plan`）里用计划清单列步骤（显示在输入框上方；没开计划模式它不列计划，你可以用 `/todo 文字` 自己加）、用选项卡片问你问题（推荐项标出，几个问题能回上一步改答案；它直接在回复里列几个方案让你挑时，Formora 也会做成同样的卡片）、记下以后要记得的事。计划还有没做完的步骤它就停下来时，Formora 会自动催它接着做，一次任务最多催 3 次。它没在工作时，计划条右端的 × 能关掉计划：没做完的步骤作废，它之后不再按这份计划做。
- 它工作时你照样能发消息：它做完手上这一步就先处理你这条，再决定原来的事要不要接着做。正在跑的命令超过 3 秒还没完，会转到后台继续跑，不让你干等；委派出去的子任务要等它交回。

## 权限模式

在 Agent 的「模型与权限」里设：

- **每次询问**：看项目文件和搜索以外的每一步都先问你。
- **允许写入**（默认）：看和写项目文件、搜索直接做；读网页、跑命令先问你。
- **全部放行**：都直接做。

删除、sudo、改写 git 历史、下载后直接运行这类危险命令，「每次询问」「允许写入」下都先问你；「全部放行」下直接执行，选它就是完全信任这个 Agent。「旁审」开关默认关，想要另一个模型在旁边把关时打开：另一个模型（「设置 → Bob」选的模型，没选就用这个 Agent 自己的）在旁边看它干活，改完文件、跑完命令的每一步和最后的回答都看一眼，没问题不出声，有问题就提醒它，分「提醒 / 担心 / 必须停」三级；每看一次多一次模型调用。「允许操作电脑」开关默认关：打开后这个 Agent 能看屏幕、点按和打字、用脚本控制其他应用（要先在「设置 → 电脑操作」给系统权限；只有官网版有）。它第一次动手前会弹卡片列出要做的步骤，你允许后这次任务里不再问；每做一步它会自己等画面稳定、看窗口里变了什么、对照自己写的预期判断有没有做到，不对就换做法，同一步最多再试 2 次，还不行就停下来问你；整件事做完，旁审会拿着最后一张截图对照你的要求验收；动手时屏幕顶部有停止条，按 ⌘ + Esc、点「停止」或在别的应用里动一下鼠标键盘就会停。Agent 不能操作 Formora 自己的窗口。打开后它还能跑 AppleScript 脚本（访达、Safari、备忘录这类支持脚本的应用，用脚本比点按更稳），能查看和运行你在「快捷指令」里做好的快捷指令；脚本第一次控制某个应用时，macOS 会问你一次。

## 群聊

- @ 谁就交给谁；@ 几个就依次回答。
- 不 @ 任何人：调度员按任务性质选一个成员——同岗位选空闲的，接着谁的活就给谁；对话里会写一行「分配给 X：理由」。
- 接力：一个成员做完自己的部分，可以交给下一个岗位（比如产品设计交给研发），对话里一行「A → B」写着交待。一条消息最多交接 6 次、50 万 token，接力中输入框上方有带「停止」的横幅。
- 群设置里可以在这个群停用某个成员。

## 委派

Agent 可以把一件界定清楚的事委派给同事或自己的「分身」（同岗位同模型，但不带这段对话），几件一起做。每件事是一个子任务，从卡片上的「打开子任务」能看过程，报告会交回给它。帮手要你批准的操作，会同时出现在原对话的卡片上。一次最多委派 8 件，同时 4 件。

## 自主运行

`/loop N` 连续跑 N 轮；`/goal 目标` 一轮一轮做，Agent 说做到了由另一个 Agent 只读复核，没通过就带着意见接着做。都最多 10 轮，随时能停。

## 记忆

Agent 会记下你的偏好、项目约定和定下来的结论；用了工具或来回好几轮之后，还会自动整理一次。每个 Agent 在每个项目各有一份，最多约 1 万 token，用 `/memory` 查看。删掉 Agent 时它的记忆一起删。每条后面的日期是最后一次写下或确认的时间：它再记一次同样的话、或者整理时发现这次又用到了，日期就更新成今天；半年多没更新的条目不再给它看，`/memory` 里单独灰色列在「很久没用到」下面，它再记一次就恢复。

## 上下文

对话太长时会自动压缩成摘要，原文折叠保留；输入框右下角的圆环是上下文占用，快满时会提示用 `/compact`。

## 子代理

子代理是按目的定义的专用助手，不是 Agent 列表里的岗位：有名字、一句话描述、自己的系统提示词、工具档位（只读 / 可写 / 可执行命令）。没有头像和自己的对话，被派活时在干净的上下文里跑一个子任务，做完交回报告。在对话里 `/agent 写清目的` 创建：你只写核心目的，模型按一份内部的「撰写指南」把名字、描述、工具档位和系统提示词都写好、直接存下，结果落在对话下方的卡片里，不用你逐字填。`/名字 任务` 直接派；Agent 也会按描述自己派。要集中查看、改或删，去「设置 → 子代理」。定义是 Markdown 文件，在项目的 `.formora/agents/` 或全局的 `~/.formora/agents/`，和 Claude Code 的 `.claude/agents/` 一个格式，项目里已有的也直接能用。内置三个：探路、评审、查资料。
