# 文件和看板

## 文件

「文件」显示当前项目文件夹的文件树，右边是预览：文本、Markdown、代码、JSON、图片、网页都能直接看。上面的搜索框按名字找文件，也能在 Finder 里打开。

- Agent 写的文件就在项目文件夹里，通常放在 PRD/ 这类目录下。对话里的保存卡片写着「文件已保存 / 文件已修改」和真实路径，点「在文件中查看」会跳过来并选中那个文件。
- 你发给 Agent 的附件和粘贴的图片会复制进项目里的「附件」目录。
- Formora 不把文件存到别的地方：你在 Finder 里看到的就是同样的文件，Agent 只能在项目文件夹里读写。
- 项目文件夹是 git 仓库时，搜索框下面有「N 个改动」按钮：点开能勾选要提交的文件、看每个文件的 diff、写提交信息（「让 Agent 起草」会按 diff 写一版），然后「提交」「提交并推送」或「提交并发 PR」。在 main 这类主分支上推送或发 PR 时会先自动建一个分支。用的是你自己电脑上的 git 和 gh，代理、登录都和终端里一样；没装 gh 会告诉你怎么装。
- Skill 的文件在你的用户目录下的 `~/.formora/skills`（官网版；App Store 版在它自己的容器里），「设置 → Skills」里能在 Finder 中打开。同一个 `~/.formora` 里还有全局 Hooks（hooks.json）、Agent 和 Bob 的记忆（memory）、MCP 服务的配置（mcp.json，密钥在钥匙串里）。

## 看板

看板是对话的另一种看法：一个对话就是一张画布，每次派活是一张卡片——谁接的、交出了什么（产出的前几行、写过的文件、耗时、token、回复次数）、现在什么状态（待开始 / 进行中 / 等待限流 / 已完成 / 已停止 / 已失败）。上游交给下游、委派出去的子任务、从画布上分出去的任务，都用线连着。左边的列表是项目里的对话，有失败的和进行中的排在前面，头像是整条链路的状态，能按名字、成员、任务搜索。

- 点一张卡：右边弹出「运行过程」，像一个小终端一样按顺序列出这张卡的全部过程——你说的话（›）、Agent 的思考（灰色斜体，不折叠）、Agent 说的话、每一步操作和结果（└），超过 5 秒的步骤标出耗时；正在跑的卡边想边写地实时出现，底部一行写着现在的状态、耗时和 token；每次打开都停在最新一行，每一行的文字可以选中复制。卡片上的对话图标跳回对话里那条消息（委派的卡打开它的子任务），文件行跳到「文件」并选中那个文件。
- 点中卡片后，底部出现输入框（就是消息区那个）：不 @ 人是给这张卡补充要求，原来的 Agent 接着做；@ 一两个人，就从这张卡下面分出子任务，这张卡的产出会一起交给他们。委派出去的卡已经结束，不能再补充，只能 @ 人分出去。画布上不新建任务，新任务从「消息」发起。
- 在单聊里 @ 一个不在对话里的角色，对话会原地变成群聊，群名就用任务名，原来的卡片不变；对话里留一条「已把「X」加入，现在是群聊…」，旁边的「重命名」打开群设置。
- 画布：滚动或拖空白处平移，按住 ⌘ 滚动或双指捏合缩放，双击空白处或 ⌘0 回到原样；卡片可以拖着重新排，「重新排列」回到自动排版（可以撤销一次）。键盘：Tab 进到卡片上，方向键在卡片间移动，回车打开，Esc 关掉。
