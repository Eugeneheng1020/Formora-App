# 设置里的每一页

- **账户**：你的名字和头像。Agent 称呼你时用这个名字。
- **模型**：模型服务商，分两组。「API 绑定」：给一家填上 API Key、测试连接，就能展开看这家的可用模型；也可以添加自定义服务商（任何兼容 OpenAI 或 Anthropic 接口的地址）。「订阅绑定」：用 ChatGPT Plus / Pro 的订阅，在浏览器里登录 ChatGPT 账号，不用 API Key（这是非官方接入）。Claude 的订阅不能这样用，要用 Anthropic 的 API Key。每家可以设工具调用的方式：自动、原生、文本（给不支持原生工具调用的模型用）。Agent 用哪个模型不在这里选，在 Agent 详情的「模型与权限」里选。
- **Skills**：全局 Skill 库：看每个 Skill 的说明和来源、导入本地文件夹、在 Finder 里打开、卸载。
- **MCP**：接入的 MCP 服务：从推荐目录接入、粘贴配置、手动填写、测试连接、浏览器登录、删除。
- **Hooks**：在固定时刻自动运行的命令或网址：发送消息时、工具执行前、工具执行后、回复结束时、对话开始时、子任务开始和结束时。写法和 Claude Code 的 Hooks 一样；全局的直接生效，项目里的要先点「启用」才会跑，文件改过要重新启用。网址可以发到飞书、企业微信、钉钉或 Slack 机器人。
- **通知**：Agent 回复时弹系统通知、播放提示音、在程序坞图标上显示未读数，三个开关。
- **电脑操作**：Agent 操作电脑要的三个系统权限：屏幕录制（截屏）、辅助功能（读窗口里的按钮和文字、点按和打字）、自动化（用脚本控制其他应用）。每一行显示有没有授权，有「请求授权」和「打开系统设置」。只有官网下载的版本有这一页的功能，App Store 版没有。哪个 Agent 能操作电脑，在它的「模型与权限」里单独打开「允许操作电脑」。
- **归档**：归档了的对话，可以恢复到列表，或者彻底删除。
- **Bob**：选 Bob 用哪个模型（默认用第一个配好的模型，那个模型没了就自动换下一个），列着能问他的事。和 Bob 说话在设置每一页右下角的圆形按钮里，点开是对话浮窗，看着背后的页面让他改，改完直接在页面上核对。

## Agent 的设置在哪

Agent 自己的配置在「Agent」区：选中一个 Agent，详情里有概览、模型与权限（主模型、备用模型、项目权限、权限模式、旁审、允许操作电脑）、Skills、MCP 几个标签。
