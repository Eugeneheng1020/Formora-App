# 设置里的每一页

- **账户**：你的名字和头像。Agent 称呼你时用这个名字。
- **模型**：模型服务商，分两组。「API 绑定」：给一家填上 API Key、测试连接，就能展开看这家的可用模型；也可以添加自定义服务商（任何兼容 OpenAI 或 Anthropic 接口的地址）。自定义平台上用 Claude 模型时，平台要是提供 Anthropic 接口，协议就选 Anthropic（地址通常比 OpenAI 的少一段 `/v1`）：Claude 的提示词缓存要请求里带标记才生效，Formora 只在 Anthropic 协议和 OpenRouter 上带，选成 OpenAI 协议就没有缓存、每一步按全价算；GPT、DeepSeek、Gemini 这些是服务端自动缓存，选哪种都一样。同一个平台上的其他模型仍走 OpenAI 协议，就配成两个服务商。「订阅绑定」：用 ChatGPT Plus / Pro 的订阅，在浏览器里登录 ChatGPT 账号，不用 API Key（这是非官方接入）。Claude 的订阅不能这样用，要用 Anthropic 的 API Key。每家可以设工具调用的方式：自动、原生、文本（给不支持原生工具调用的模型用）。Agent 用哪个模型不在这里选，在 Agent 详情的「模型与权限」里选。清除某家的 API Key 前，Formora 会先看有没有 Agent 在用它：有就不让清，写明是几个 Agent，先去它们的「模型与权限」换掉。
- **Skills**：全局 Skill 库（官网版放在 `~/.formora/skills`）：看每个 Skill 的说明和来源、导入本地文件夹、在 Finder 里打开、卸载。
- **MCP**：接入的 MCP 服务：从推荐目录接入、粘贴配置、手动填写、测试连接、浏览器登录、删除。
- **SubAgent**：集中看和管理所有子代理，按来源分组：本项目（`.formora/agents`）、全局（`~/.formora/agents`）、内置（Formora 自带的三个）、Claude Code（`.claude/agents`，只读，去 Claude Code 里改）。每行显示名字、一句话描述、工具档位（只读/可写/可执行）、有没有指定模型。Formora 自己的可以「编辑」（打开创建弹窗、字段都填好，改名字等于改命令）和「删除」（先问一次，会删掉文件）。右上角「新建」空手创建一个；在消息里用 `/agent 目的` 让 Agent 按目的起草一个。
- **Hooks**：在固定时刻自动运行的命令或网址：发送消息时、工具执行前、工具执行后、回复结束时、对话开始时、子任务开始和结束时。写法和 Claude Code 的 Hooks 一样；全局的直接生效，项目里的要先点「启用」才会跑，文件改过要重新启用。网址可以发到飞书、企业微信、钉钉或 Slack 机器人。
- **通知**：Agent 回复时弹系统通知、播放提示音、在程序坞图标上显示未读数，三个开关。
- **电脑操作**：Agent 和 Bob 操作电脑要的三个系统权限：屏幕录制（截屏）、辅助功能（读窗口里的按钮和文字、点按和打字）、自动化（用脚本控制其他应用）。每一行显示有没有授权，有「请求授权」和「打开系统设置」。只有官网下载的版本有这一页的功能，App Store 版没有。哪个 Agent 能操作电脑，在它的「模型与权限」里单独打开「允许操作电脑」；Bob 的开关在「设置 → Bob」。
- **归档**：归档了的对话，可以恢复到列表，或者彻底删除。
- **用量**：这段时间（今天 / 7 天 / 30 天 / 全部）Agent 回复用了多少 token、折成多少钱，按对话、按 Agent、按模型看。钱是按下面的「单价」表算的：Formora 内置了常见模型的参考单价，以服务商官网为准，每个模型的币种和输入、输出单价都能直接改，改过的标「自定」，「恢复默认」回到参考值；没有单价的模型只算 token 不算钱。「每月预算」填了金额后，这个月的花费超过它会通知你一次。
- **Bob**：选 Bob 用哪个模型（默认用第一个配好的模型，那个模型没了就自动换下一个），「权限模式」和 Agent 一样三档，默认「每次询问」；接入 MCP 服务、清空记忆、会删数据的 MCP 工具不管哪一档都先问你；危险命令在「全部放行」下直接执行。「允许操作电脑」开关默认关：打开后 Bob 能看屏幕、点按和打字、用脚本控制其他应用（只有官网下载的版本有，要先在「电脑操作」里授权）；看屏幕不问，每次回答第一次动手时问你一次（「全部放行」时不问），屏幕顶部的停止条随时能停。页面下方是一叠「能问他什么」的卡牌，一次一张，写着问题和 Bob 的回答示例，左右翻，「问 Bob」打开浮窗直接问。和 Bob 说话在设置每一页右下角的圆形按钮里，点开是对话浮窗，看着背后的页面让他改，改完直接在页面上核对。

## Agent 的设置在哪

Agent 自己的配置在「Agent」区：选中一个 Agent，详情里有概览、模型与权限（主模型、备用模型、项目权限、权限模式、旁审、允许操作电脑）、Skills、MCP 几个标签。
- **关于**：版本号；「检查更新」和「自动检查更新」开关（新版本从 GitHub 取，每天自动查一次，菜单「Formora → 检查更新…」也一样）；「导出诊断包」把崩溃报告、最近 7 天的运行日志、最近 24 小时改动过的对话和版本信息打成一个 zip 放到桌面（密钥先遮蔽，不会自己发出去），出了问题把这个 zip 发给开发者；「打开日志文件夹」；「去 GitHub 反馈」。
- **分阶段模型**（用户 2026-09-16）：一个 Agent 可以给不同阶段配不同模型——计划模式出方案、旁审复核、读图、以及起任务名/压缩上下文这类省事的杂活，各自可指定一个，留空就用主模型。备用模型只留一个，任何模型不可用时都退到它兜底。
