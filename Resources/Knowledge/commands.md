# 输入框里的指令

在对话的输入框里，行首打 `/` 会弹出指令列表，接着打字会过滤，↑↓ 选、回车执行；要写参数的指令选中后会等你接着打。打 `@` 会弹出项目里的文件，群聊里先列成员。

选中的 @成员、@文件显示成色块，开头的 `/指令` 是琥珀色色块。每条消息鼠标移上去，时间旁边有「复制」，右键也能复制；也可以用鼠标拖选气泡里的一段字再 ⌘C（Agent 的回复一次选一段，跨不了段落）。改自己发过的消息：回车重新发送，Shift+回车换行，Esc 取消。

输入框的按键：回车发送，Shift+回车或 ⌥+回车换行；输入框空着时按 ↑ 调出你上一条发的话，再按往前翻，↓ 往回；Agent 正在回复时按 Esc 停止。打开或切换对话后光标就在输入框里，直接打字就行。输入框空着、没有在跑时按 Tab，这条对话的主模型读完整段对话，给出你接下来最可能说的一句话，灰字显示在输入框里；再按一次 Tab 整句采用，Esc 或直接打字就不要它。不按 Tab 就不会去算，也不花钱。`/` 或 `@` 的列表开着时，Tab 还是选中列表里高亮的那一项。

## 指令

| 指令 | 作用 |
|---|---|
| `/clear` | 清空当前对话的消息和计划。会先弹确认，清掉就找不回来；对话本身留在列表里。 |
| `/cost` | 这条对话用了多少 token、调用了几次模型，按模型分开算。点输入框右下角的圆环也能打开。 |
| `/plan` | 切换计划模式（和输入框下方的 `plan: on / off` 同一个开关）：开着时每件事 Agent 都先看、先问、出方案，你点「按这个计划做」它才动手，执行这份计划时写文件、跑命令不再逐步问你（七类危险命令照样问）；计划模式一直开着，下一件事照样先出方案，再点一次才关。`/plan 要做的事` 直接带着这件事进入计划模式。 |
| `/compact` | 压缩上下文：把前面的对话整理成摘要，原文折叠保留，不会删掉。`/compact 重点` 指定摘要里一定要留下的内容。 |
| `/todo` | 看当前的计划清单；`/todo 文字` 往清单里加一项。没开计划模式时 Agent 自己不列计划，清单只来自计划模式和你加的项；它没在工作时，输入框上方计划条的 × 关掉计划。 |
| `/memory` | 看这条对话用得到的记忆：全局、本项目、这个 Agent 自己的三层，只读；带正文的能展开。记错的在对话里那一行点「撤销」，或者说一句「忘掉 XX」。 |
| `/review` | 请旁审（另一个模型）把 Agent 最近一轮做的完整审一遍：先给结论「可以交付」或「需要改」，再按级别列出问题——P0 挡住交付、P1 这次就该修、P2 以后修、P3 可改可不改；`/review 重点` 指定重点看什么。有 P0、P1 时 Agent 会回去先改这些。 |
| `/side` | 岔开问一句：`/side 问题`。当前对话的位置换成一个临时对话，同一个 Agent 看得到主对话、只看不改，这里的问答不进主对话；点「回到主对话」就清掉。 |
| `/loop` | 自主运行 N 轮：`/loop 3 接着完善这份需求`。最多 10 轮，每轮在对话里留一条分隔线，输入框上方的横幅能随时停。 |
| `/goal` | 朝一个目标自主运行，Agent 说做到了由另一个 Agent 复核：`/goal 把会员体系的 PRD 写完`。最多 10 轮、50 万 token。 |
| `/export` | 把对话导出成 HTML 文件。 |
| `/dump` | 把整段对话复制到剪贴板。 |
| `/help` | 列出这个对话能用的全部指令。 |
| `/git` | 看仓库状态和最近的提交，只有研发 Agent 有。 |
| `/effort` | 调推理强度：在输入框上方弹出这个模型真有的档位（off / low / medium / high / xhigh / max 之类，只有开关的模型是 off / on），当前的打勾，↑↓ 选、回车换；也可以直接打 `/effort max`。只影响这一条对话，新对话默认 high。 |
| `/model` | 在输入框上方弹出模型列表，直接换这个 Agent 的主模型：列出所有配了 Key 的服务商的全部模型，按服务商分组、当前的打勾；接着打关键词就只剩匹配的（`/model claude`），↑↓ 选、回车切换。换的是主模型，分阶段模型不动；群聊里换的是最近回答的那位。看板卡片的输入框一样。 |
| `/skills 描述` | 创建一个 Skill：写清要它会什么，比如 `/skills 按我们的格式写周报`。模型一次写好直接存下，并为这条对话的 Agent 启用，对话里出现一行「已创建 Skill 名字」。 |
| `/mcp 描述` | 接入一个 MCP 服务：写服务名（推荐目录里的，比如 `/mcp GitHub`）、一个网址，或贴一段配置；要令牌的直接写在后面。模型写好接入参数后，输入框上方先停一张卡片写明要连哪个地址或运行哪条命令，点「允许」才接入。 |
| `/hooks 描述` | 在当前项目创建一个 Hook：写清什么时候做什么，比如 `/hooks 每次改完 Swift 文件就跑 swiftformat`。输入框上方先停一张卡片写明时刻和完整的命令，点「允许」才存下，存下就启用。 |
| `/agent 目的` | 创建一个子代理：你只写清它要替你做什么，回车就自动开始——模型把名字、中文简介、工具档位和整段系统提示词都写好并保存，全程没有弹窗、不用你填任何东西；名字是英文的（比如 code-reviewer），撞了名会自动加编号。做完对话里出现一行「已创建子代理 code-reviewer」和它的简介、指令；在看板的输入框里打的，这一行在那张卡片的「运行过程」浮窗里。没成也是一行，写着原因。想看全部去「设置 → SubAgent」（那里只看和删除）。 |
| `/名字 任务` | 名字是某个子代理的：把这件事直接交给它，它在自己的子任务里做完，报告回到对话里。内置的有 `/scout`（只读摸清代码或文档）、`/reviewer`（按 P0–P3 列问题）、`/researcher`（上网查、带来源）。Agent 也会按描述自己派它们。 |
| `/skill:名字` | 用这个 Agent 启用的某个 Skill 做事，比如 `/skill:requirement-brief 购物车挽回`。`/` 菜单里的「Skills」一组列着能用的。 |

## @

- `@文件`：把项目里某个文件发送那一刻的内容一起发给 Agent。
- 群聊里 `@成员名`：交给这个成员；@ 了几个就依次回答，后面的能看到前面的回答。不 @ 任何人时，调度员按任务性质分配给一个成员。

## 回复中再发消息

Agent 还在做的时候，你发的话会排在它下面，它做完手上这一步就会看到，用来补充或纠正。输入框右下角的停止按钮随时能停，已经写出来的部分会保留。

## Bob 的指令

和 Bob 说话的浮窗里，输入框打 / 列出的是他自己的指令（Agent 对话里的计划模式、自主运行、旁审这些在这里用不了）：

- `/clear`：清空和 Bob 的对话
- `/memory`：看 Bob 读得到的记忆——全局那层（关于你的）和他自己那层（不分项目），只读；要他忘掉哪条，直接跟他说
- `/help`：列出这里能用的指令
- `/dump`：把和 Bob 的对话复制到剪贴板
- `/export`：把和 Bob 的对话导出成 HTML 文件
- `/skills 描述`、`/mcp 描述`、`/hooks 描述`：和对话里一样是创建——Skill 直接存，MCP 和 Hook 在浮窗里先停一张卡片等你「允许」
- `/model`、`/notifications`、`/computer`：切换浮窗后面的设置页
- `/skill:名字 要做的事`：按某个 Skill 的做法来做，所有已安装的 Skill 都能用
