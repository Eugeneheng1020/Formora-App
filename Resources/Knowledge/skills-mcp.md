# Skill 和 MCP

## Skill

Skill 是一份可复用的做法说明：一个文件夹，里面有 SKILL.md，可以带参考资料和脚本。Agent 平时只看得到每个 Skill 的名字和一句说明，要做相应的事时才读全文照做。

- **全局安装、按 Agent 启用**：Skill 装在「设置 → Skills」的全局库里；哪个 Agent 能用，在那个 Agent 的 Skills 标签里打开。装了不等于启用。
- **三种来源**：Formora 内置的 10 个（比如需求澄清、写实施计划，还有处理 Word、Excel、PPT、PDF 文件的）；从本地文件夹导入（文件夹里要有 SKILL.md）；让 Bob 或 Agent 写一个。
- 在对话里用 `/skill:名字 要做的事` 指定用哪个 Skill。
- Bob 创建的 Skill 进全局库，不替任何 Agent 启用，要用就去 Agent 的 Skills 标签打开。
- Bob 自己能用所有已安装的 Skill，不用给他启用。
- 在「设置 → Skills」里能看每个 Skill 的说明和文件、在 Finder 里打开它的文件夹、卸载。

## MCP

MCP 是给 Agent 接外部工具箱的方式，比如 Figma、Notion、GitHub、Linear。

- **在哪接**：「设置 → MCP」，从推荐目录一键接入，也可以粘贴配置或手动填地址；也可以让 Bob 接。
- **推荐目录**：30 个服务分五组——办公协作、设计、开发部署、查资料、商务。多数一键添加：要登录的点「浏览器登录」，Context7、DeepWiki、Cloudflare 文档、Hugging Face 不用登录。有的要填东西：令牌（GitHub、Figma 等），文件夹（Obsidian 选笔记库、文件系统选允许读写的文件夹），或者好几项（飞书的 App ID 和 App Secret）。在本机启动的服务都固定在检查过的版本，只有官网版能用。
- **在对话里给令牌**：要令牌的服务，可以直接把令牌贴给 Bob 或 Agent，比如「接入 GitHub，令牌 ghp_…」。Formora 在发给模型之前就把它换成占位符，模型看不到真值；接入时再换回真值，存进钥匙串。常见服务的令牌格式都认得；别的格式，写在「令牌」「密钥」「key」「token」后面也会被遮住。
- **测试连接**：接入后测一次；需要登录的会打开浏览器，登录完回到 Formora 就好。登录过期（401）要重新登录。官网版也能接要在本机启动进程的服务（stdio，比如用 npx、uvx 装的那些）：它在当前项目文件夹里启动，只拿到几个必要的环境变量（包括你终端里设的网络代理）和你给它配的；第一次启动可能要下载，最长等 60 秒；它一直开着供 Agent 反复用，停用、删除、改配置或退出 Formora 时关掉。Agent 或 Bob 在对话里接这种服务时，确认卡片会写出它要运行的完整命令。App Store 版接不了。
- **Figma**：推荐目录里的「Figma」填 Figma 个人访问令牌（在 Figma 的「设置 → 安全 → 个人访问令牌」里生成，至少勾选读取文件内容）。它用开源的 Framelink 服务读设计稿的图层、样式、文字和切图，只读，不改画布；在本机启动，要装了 node，只有官网版能用。有 Figma 付费版 Dev 或 Full 席位的，也可以用「Figma 桌面版」：先打开 Figma 桌面版和一个设计文件，按 Shift D 切到 Dev Mode，在右侧检查面板的 MCP 一栏点「启用桌面 MCP 服务」，再回 Formora 测试连接；用的时候 Figma 要一直开着。Figma 官方的网络服务只让它名单上的应用连，Formora 还不在名单上。
- **按 Agent 授权**：在 Agent 的 MCP 标签里选它能用哪些服务、每个服务的全部工具还是部分工具。Bob 不用授权：已启用的服务，它的全部工具他都能用；只读的直接用，会改东西的按他的权限模式来（默认每一步先问你），服务标明会删数据的工具不管哪一档都先问。
- **Agent 怎么用**：每个工具单独出现在 Agent 手里，名字是 `mcp__服务__工具`；只读的工具直接用，会改东西的按 Agent 的权限模式来。
- Agent 在对话里也能接入新的 MCP 服务，但一定先问你；接好之后同样要在 Agent 的 MCP 标签里启用。
